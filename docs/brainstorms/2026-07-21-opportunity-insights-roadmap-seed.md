# Opportunity Insights

## Problem Frame

Staff want help identifying missed communication opportunities, under-served segments, and follow-up gaps. The system should surface useful, reviewable insights without creating a noisy pile of suggestions.

## Seed Requirements

- R1. The system should surface people or households who likely need follow-up but have not received relevant communication.
- R2. The system should identify segments with low or missing communication coverage.
- R3. The system should connect giving lifecycle or trend changes to communication opportunities.
- R4. Insights should be reviewable recommendations, not automatic sending decisions.
- R5. Insights should explain the evidence behind each recommendation in staff-readable language.

## Scope Boundaries

- Do not automatically send communication from an insight.
- Do not present noisy or low-confidence recommendations as urgent work.
- Do not expose unnecessary donor PII or financial detail in insight explanations.

## Questions To Pick Up

- What counts as a missed opportunity?
- Which opportunities should become staff tasks, campaign suggestions, or dashboard insights?
- How should the system avoid overwhelming staff with noisy recommendations?
