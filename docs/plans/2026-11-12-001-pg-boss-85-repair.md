# Scope and evidence

PR #85 updates pg-boss 12.15.0 to 12.38.2. Daily synthetic assessment found the real jobs loader treats the new getQueueStats time-series array as QueueResult and displays healthy zero counts. Its Schedule test fixture also lacks required fields. Rock, auth, communication decisions and Prisma models remain outside this repair.

Reassess advisories and dependency composition; reuse upstream evidence only where versions/composition are identical.
